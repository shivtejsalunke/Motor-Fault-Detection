# Dataset card

**Current status:** no external dataset has been selected, licensed, or bundled in this repository.

Before accepting a dataset, record:

- Official title, source URL, citation/publication, retrieval date and checksum.
- License and redistribution rules; access approval if applicable.
- Machine and motor/bearing details, labels and labeling protocol, load/speed, acquisition sessions, recording IDs and machine IDs.
- Sampling frequency in Hz, sensor axis, physical unit (for example m/s² or g), ADC scaling and calibration.
- Number/duration of recordings, class balance, missing or saturated samples, and known biases.
- Window length/hop and filtering choices.
- Train/test grouping methodology and known limitations.

Until this card is completed for a verified real dataset, automated-test metrics demonstrate code behavior only and are not evidence of real-world fault-detection accuracy.
