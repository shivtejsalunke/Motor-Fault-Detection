# Problem statement and intended use

Vibration-based condition monitoring asks whether a fixed-length vibration window contains signal characteristics associated with healthy or faulty machine operation. This repository starts with interpretable time-domain and frequency-domain features and a deterministic baseline classifier.

The project is intended for method prototyping, software validation, and reproducible experiments. It is not a certified diagnostic, safety instrument, or predictive-maintenance product. A meaningful evaluation requires a well-described dataset and independent recording/machine groups, plus review of acquisition conditions and label provenance.
